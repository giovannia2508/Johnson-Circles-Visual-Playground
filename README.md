# Johnson-Circles-Visual-Playground
Interactive playground and visual proof for Johnson's Circles.

I was playing around with a problem on Susan Jane Colley's Vector Calculus and stumbled upon Johnson's Circles. I built this visual proof based on Roger A. Johnson's 1916 publication in the American Mathematical Monthly.

Here is the site: https://giovannia2508.github.io/Johnson-Circles-Visual-Playground/
